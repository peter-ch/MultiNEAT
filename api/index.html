    Python API reference¶

    import MultiNEAT as NEAT gives access to everything below. The guides explain how the pieces fit together - start with the tutorial.

    Lists returned by the library (pop.Species, species.Individuals, genome.LinkGenes, net.neurons, ...) are references into the C++ objects: changing an element changes the object. They support len(), indexing, iteration, append() etc. like Python lists, and Python lists and tuples are accepted wherever such a list is expected.

    (This page is generated by docs/tools/gen_api.py.)

    Enumerations¶

    • ActivationFunction: SIGNED_SIGMOID, UNSIGNED_SIGMOID, TANH, TANH_CUBIC, SIGNED_STEP, UNSIGNED_STEP, SIGNED_GAUSS, UNSIGNED_GAUSS, ABS, SIGNED_SINE, UNSIGNED_SINE, LINEAR, RELU, SOFTPLUS

    Functions¶

    Function
    GetGenomeList(pop) Returns all genomes of the population as a list. The genomes are references - changing their fitness changes the population.
    ZipFitness(genome_list, fitness_list) Sets the fitness of every genome and marks it as evaluated.
    EvaluateGenomeList_Serial(genome_list, evaluator, display=True, show_elapsed=False) Evaluates the genomes one after another and returns the list of fitness values. evaluator is a callable that takes a Genome and returns its fitness.
    EvaluateGenomeList_Parallel(genome_list, evaluator, cores=None, display=True, ipython_client=None) Evaluates the genomes in parallel processes and returns the list of fitness values. evaluator is a callable that takes a Genome and returns its fitness. It must be picklable (defined at the top level of a module). The genomes are pickled together with their traits. Uses concurrent.futures with cores processes (all CPUs by default), or an IPython cluster when an ipyparallel Client is given.
    Draw(x, size=(300, 300), substrate=False) Returns an image (NumPy uint8 array) of a NeuralNetwork or a Genome's phenotype.
    DrawPhenotype(image, rect, nn, neuron_radius=15, max_line_thickness=3, substrate=False) Draws a network into a NumPy image within rect = (x, y, width, height) using OpenCV. With substrate=True the neurons are drawn at their substrate coordinates.
    plot_nn(nn, ax=None, is_substrate=False, details=False, invert_yaxis=True, connection_alpha=1.0) Draws a NeuralNetwork or a Genome's phenotype with Matplotlib.
    render_nn(nn, ax=None, is_substrate=False, details=False, invert_yaxis=True, connection_alpha=1.0) Draws an already laid out NeuralNetwork into a Matplotlib axis.
    Genome2NX(g, with_inputs=False, with_weights=False) Converts a genome to a networkx DiGraph with the traits as node and edge attributes.
